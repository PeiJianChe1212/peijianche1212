1. 欢迎使用 PeiLink
================================================================================

欢迎加入 PeiLink 内测！

PeiLink 是一款以 AI 角色为核心的陪伴与生活世界应用。你可以创建属于
自己的 AI 角色，与他们聊天、共同积累记忆、浏览他们的生活动态，并在
PeiLink Life 中记录属于你们的纪念日和生活点滴。

当前版本为 Test RC 内测版，部分功能仍在开发中。本说明书会明确区分
"已经可以使用"和"尚未开放"的功能，帮助你顺利体验。

【提示】内测期间遇到任何问题，请优先使用应用内的"反馈与建议"功能
提交，我们会认真处理每一条反馈。

================================================================================
2. PeiLink 是什么
================================================================================

PeiLink 不是一个简单的聊天工具，而是一个围绕 AI 角色构建的完整世界。

它的核心组成包括：

- 角色：你创建或导入的 AI 角色，每个角色有独立的资料、记忆和生活。
- 聊天：与角色进行一对一对话，也可以创建群聊与多个角色同时聊天。
- Memory（记忆）：角色会记住与你之间重要的事情，你可以查看、编辑和
  管理这些记忆。
- Echo：角色发布的生活动态，类似朋友圈，你可以点赞、评论和互动。
- PeiLink Life：生活世界首页，聚合多个角色的动态，包含日历、纪念日
  等本地工具。
- Guide：内置的使用说明中心，随时可以搜索问题答案。

【注意】PeiLink 本身不提供 AI 模型服务。你需要自行配置 AI 模型的
API 才能与角色聊天。具体请参考第 6 章"配置模型与 API"。

4. 第一次使用推荐流程
================================================================================

如果你是第一次使用 PeiLink，建议按照以下顺序操作：

第一步：填写个人资料
  打开侧边栏 → 点击顶部个人资料卡片 → 设置头像、昵称、签名等。

第二步：配置模型与 API
  侧边栏 → 设置 → 模型与 API → 配置聊天用的 API Key 和模型。
  配置完成后建议先测试连接是否正常。

第三步：创建角色或导入 .pei
  方式 A：消息页右上角 + 按钮 → 新建角色
  方式 B：消息页右上角 + 按钮 → 导入角色（选择 .pei 文件）

第四步：开始聊天
  在消息列表中点击角色，进入聊天页发送第一条消息。

第五步：体验更多功能
  查看角色状态 → 体验 Memory → 浏览 Echo → 打开 PeiLink Life
  → 新增纪念日 → 使用 Guide 搜索帮助。

【提示】如果还没有配置 API，角色无法回复消息，但你仍然可以浏览
Echo、Life、日历、纪念日等不需要 AI 的功能。

5. 个人资料
================================================================================

个人资料是你在 PeiLink 中的身份信息，与角色无关，全局只有一份。

【进入方式】
  方式 A：在任意主页面点击左上角头像，打开侧边栏，再点击顶部的
          个人资料卡片。
  方式 B：PeiLink 主应用页面点击左上角头像。

【可编辑内容】

基本资料：
- 头像：点击头像区域可以更换图片。
- 昵称：你的显示名称。
- 签名：一句话自我介绍。

个人信息：
- 性别：男 / 女 / 其他 / 不透露。
- 生日：选择日期。
- PeiLink ID：系统自动生成的唯一标识，不可修改。

【注意】
- 地区信息在当前测试版中已从界面移除，无法设置。
- 旧版的"我的人设"入口已移除，当前角色级身份设定请使用"我的个人
  设定"（见第 10 章），它与全局个人资料是分开的。

6. 配置模型与 API
================================================================================

PeiLink 本身不提供 AI 模型，你需要使用自己的 AI 服务 API 才能让
角色回复消息。

【进入方式】
  侧边栏 → 设置 → 模型与 API

【三套独立配置】

当前测试版将 API 分为三套，彼此独立：

1. 聊天 API（Chat API）
   用于角色文字对话，是最核心的配置。

2. 识图 API（Vision API）
   用于你在聊天中发送图片后，AI 识别图片内容。
   可以选择复用聊天 API 的 Key，也可以单独配置。

3. 图片生成 API（Image Generation API）
   用于角色生成图片相关功能。
   独立配置，与聊天和识图互不影响。

【聊天 API 支持的服务商】

- DeepSeek（默认推荐）
- 火山方舟（Volcengine Ark）
- OpenAI
- 自定义（Custom，可填入任意兼容 OpenAI 格式的接口）

【需要填写的信息】

- API Key：从对应服务商获取的密钥。
- Base URL：接口地址，选择预设服务商时会自动填充，自定义模式需手动
  填写。
- 模型名称：选择或输入要使用的具体模型。

【配置建议】

1. 如果你是第一次使用，推荐选择 DeepSeek，注册和获取 API Key 比较
   方便。
2. 填写完成后，页面会提供连接测试功能，建议先测试确认配置正确。
3. 识图功能如果你的聊天模型本身支持多模态，可以选择"复用聊天 Key"，
   不需要额外配置。

【关于费用】

PeiLink 不收取任何 AI 调用费用。你使用自己配置的 API 时，实际产生
的费用、额度限制和服务可用性完全由对应的模型服务商决定。请关注你
在各服务商处的账户余额和用量。

7. 创建角色
================================================================================

【进入方式】
  方式 A：PeiLink 主应用 → 消息页 → 右上角 + 按钮 → 新建角色
  方式 B：PeiLink 主应用 → 羁绊页 → 底部"添加角色"按钮 → 新建角色
  方式 C：AI 世界桌面 → 应用页 → 点击"创建"图标

【创建时需要填写】

基础信息：
- 名称（必填）：角色的名字。
- 性别（必填）：角色的性别。
- 角色简介：用于角色资料页公开展示的简短介绍。

角色设定：
- 性格（必填）：详细描述角色的性格特点，这会直接影响角色的说话方式
  和行为风格。建议写得越具体越好。

关系与生活：
- 角色关系：描述角色与你或其他角色的关系，例如"朋友""哥哥""同事"
  等。

形象：
- 头像：可以上传一张图片作为角色的聊天头像。
- 背景图：可以上传一张图片作为角色的背景。

【创建后】

角色创建完成后，会自动出现在消息列表和羁绊列表中。你可以随时进入
角色资料页补充更详细的设定（外貌、背景故事等），详见第 9 章。

【提示】角色的性格描述是影响 AI 表现最关键的因素。建议花时间认真
填写，角色会因此更加鲜明和稳定。

================================================================================
8. 导入 .pei 角色
================================================================================

.pei 是 PeiLink 的角色文件格式，包含角色的完整资料，可以用于备份、
迁移和分享。

【进入方式】
  PeiLink 主应用 → 消息页 → 右上角 + 按钮 → 导入角色

【导入步骤】

1. 点击"导入角色"后，会打开文件选择器。
2. 选择一个 .pei 格式的文件。
3. 应用会解析文件并显示角色预览信息。
4. 确认无误后点击导入，角色就会添加到你的角色列表中。

【注意】
- 导入的角色会作为一个新角色存在，不会覆盖你已有的同名角色。
- 如果 .pei 文件中包含 Memory 等数据，会一并导入。
- 导入后建议先进入聊天测试一下角色是否正常。

9. 角色资料与角色管理
================================================================================

每个角色都有独立的资料页面和管理入口。

【角色资料页】

进入方式：
- 聊天页 → 点击右上角"..."按钮 → 角色资料
- 聊天页 → 点击角色头像 → 角色资料
- 角色管理页 → 点击对应角色 → 角色资料

角色资料页包含：

资料完成度：
- 显示基础资料、外貌设定、角色档案的完成百分比，帮助你了解还有哪些
  信息可以补充。

资料分类：
- 基础资料：名称、性别、简介等基本信息。
- 外貌设定：角色的外貌描述。
- 性格设定：角色的性格特点。
- 背景故事：角色的过往经历和世界观。
- 关系资料：角色与他人的关系。
- 角色档案：更结构化的角色档案信息。

最终 Prompt 预览：
- 点击右上角眼睛图标，可以查看当前角色资料、档案、用户资料与 Memory
  组合后发送给 AI 的完整内容。这有助于你了解 AI 实际看到了什么信息。

【角色管理页】

进入方式：
- 侧边栏 → 角色管理

角色管理页会列出所有角色，每个角色可以进行以下操作：

- 角色资料：进入角色资料详情页。
- Memory：进入该角色的记忆管理页面。
- 导出角色：将角色导出为 .pei 文件进行备份。
- 重新开始角色：清理角色的运行数据并重新初始化（详见第 22 章）。
- 删除角色：永久删除该角色（详见第 22 章）。

【提示】角色管理页和聊天设置页中的操作是一致的，你可以从任意一个
入口进行管理。

10. 我的个人设定
================================================================================

"我的个人设定"是角色级别的身份设定，表示"你在当前角色世界里的身份"。

【进入方式】
  聊天页 → 输入框左侧"更多"按钮 → 我的个人设定

【可编辑内容】
- 设定名称：你在这个角色世界中的名字。
- 性别：你在这个角色世界中的性别。
- 设定描述：详细描述你在这个角色世界中的身份、背景和特点。

【重要说明】

"我的个人设定"与全局个人资料（第 5 章）是完全不同的两个功能：

- 全局个人资料：你在整个 PeiLink 中的身份，所有角色共用。
- 我的个人设定：仅针对当前角色，每个角色可以有不同的设定。

【测试版说明】

当前测试版中，"我的个人设定"属于角色级资料功能，你可以正常填写和
保存。但需要注意的是，这套设定目前尚未完全接入聊天时 AI 读取的上下
文中。也就是说，填写后 AI 不一定会立即按照这些资料来聊天。

后续版本会逐步完善这一功能的接入。当前你可以将其视为角色资料的补充
记录，不要完全依赖它来影响 AI 对话。

11. 开始聊天
================================================================================

【进入聊天】
  在消息列表中点击任意角色，即可进入一对一聊天页。
  群聊请在消息列表中点击群聊会话进入。

【聊天界面说明】

顶部：
- 左侧：返回按钮。
- 中间：角色头像、名称、关系标签和在线状态。点击角色名称区域可以
  查看角色当前活动详情。
- 右侧："..."按钮，打开聊天设置。

中间：
- 消息列表，显示你和角色的对话记录。
- 长按消息可以调出消息操作菜单。
- 点击角色头像可以进入角色资料页。

底部：
- 输入框：输入文字消息。
- 发送按钮：发送消息。
- 更多按钮（"+"或"..."）：展开更多功能面板。

【更多功能面板】

点击输入框旁的更多按钮，可以展开以下功能：

已开放：
- 我的个人设定：打开角色级身份设定页面。
- 图片：从相册选择图片发送，AI 可以识别图片内容（需配置识图 API）。
- 红包：发送红包互动。
- 让 Ta 换头像：请求角色更换头像。

暂未开放（点击会提示"敬请期待"）：
- 文件
- 语音通话
- 视频通话

【群聊】

当前测试版支持创建群聊，与多个 AI 角色同时聊天。

创建方式：
  消息页右上角 + 按钮 → 页面底部"创建群聊"区域 → 去创建

群聊会出现在消息列表中，与单聊区分显示。群聊支持置顶和消息免打扰
标记。

【提示】如果 AI 长时间不回复，请检查：
1. API 是否配置正确，Key 是否有效。
2. 网络连接是否正常。
3. 服务商账户是否有余额或额度。

12. 角色在线状态
================================================================================

在消息列表和聊天页顶部，你会看到角色的当前状态。

【支持的状态】

- 在线：角色当前可用，可以正常回复。
- 忙碌中：角色正在忙于其他事情。
- 休息中：角色正在休息。
- 睡觉中：角色正在睡觉。
- 外出中：角色外出了。
- 听歌中：角色正在听歌。

【状态来源】

这些状态不是 AI 随机编造的，而是来自角色现有的活动 / 生活数据映射。
聊天页和消息列表使用同一套状态逻辑，因此两边显示的状态是一致的。

【提示】状态仅作展示用途，不影响你发送消息。即使角色显示"忙碌中"
或"睡觉中"，你仍然可以发送消息，角色会在合适的时候回复。

13. 聊天背景与个性装扮
================================================================================

PeiLink 提供个性装扮功能，可以自定义聊天界面的外观。

【进入方式】
  方式 A：侧边栏 → 个性装扮
  方式 B：聊天页 → 右上角"..." → 设置当前聊天背景

【装扮分类】

个性装扮页面有四个标签页：

1. 推荐
   展示当前使用的主题预览，以及背景、气泡、字体的推荐搭配。

2. 背景
   以网格形式展示所有可选的聊天背景，包括纯色渐变和图片背景。
   点击任意背景即可应用。

3. 聊天气泡
   展示不同风格的消息气泡样式，包括颜色、圆角等。
   点击即可切换。

4. 字体
   展示不同的字体样式，点击即可应用到聊天文字。

【说明】
- 背景、气泡、字体可以自由搭配，不强制使用成套主题。
- 装扮设置是全局的，会应用到所有聊天界面。
- 当前测试版提供的是内置主题包，暂不支持自定义上传背景图片。

================================================================================
14. Memory 使用说明
================================================================================

Memory（记忆）是 PeiLink 中非常重要的功能。它让角色能够记住与你之
间重要的事情，而不是每次聊天都从零开始。

【Memory ≠ 聊天记录】

这是最容易混淆的一点，请务必理解：

- 聊天记录：你和角色之间的每一条对话，按时间顺序保存。
- Memory：从聊天中提炼出的重要信息，经过整理和审核后单独保存，角色
  在后续聊天中会参考这些记忆。

删除聊天记录不会自动删除长期 Memory，两者是独立存储的。

【进入方式】
  方式 A：聊天页 → 右上角"..." → Memory
  方式 B：角色管理页 → 对应角色 → Memory

【Memory 页面功能】

页面顶部有两个标签：

1. 长期 Memory
   已经审核通过、角色会在聊天中参考的记忆。

2. 待审核
   新整理出来、等待你确认是否保留的记忆。

【长期 Memory 的操作】

- 手动新增：点击右下角 + 按钮，手动添加一条记忆。
- 编辑：点击任意记忆可以修改内容。
- 搜索：顶部搜索框，可以按关键词搜索记忆。
- 分类筛选：按记忆类型筛选（经历、偏好、人物、秘密、其他）。
- 置顶：重要的记忆可以置顶，置顶记忆会排在最前面。
- 归档：不再需要但不想删除的记忆可以归档。
- 恢复：归档的记忆可以恢复到长期列表。
- 删除：永久删除这条记忆。

【多角色独立】

每个角色拥有自己独立的 Memory，不会把 A 角色的记忆自动混到 B 角色
中。你在 Memory 页面看到的，永远是当前角色的记忆。

================================================================================
15. 从聊天整理 Memory
================================================================================

PeiLink 可以自动从当前聊天中整理出值得记住的信息。

【操作方式】
  进入 Memory 页面 → 点击"从当前聊天整理记忆"按钮

【整理流程】

1. 点击按钮后，应用会分析当前角色的聊天记录。
2. 分析完成后，整理出的记忆不会直接进入长期 Memory，而是先进入
   "待审核"列表。
3. 你需要逐条查看待审核的记忆，决定是保留还是拒绝。

【待审核记忆的操作】

- 采纳：确认这条记忆有价值，移入长期 Memory。
- 拒绝：这条记忆不重要或不准确，直接删除。
- 编辑：先修改内容再采纳。

【为什么要审核？】

自动整理可能会把不重要的内容也提取出来，或者出现理解偏差。由你来
审核，可以确保角色记住的信息是准确和有意义的。

【提示】整理 Memory 会调用 AI 模型，因此需要配置有效的聊天 API。
整理过程中请耐心等待。

16. Echo 使用说明
================================================================================

Echo 是 PeiLink 中角色的生活动态功能，类似朋友圈。角色会发布自己的
生活动态，你可以浏览、点赞和评论。

【进入方式】

公共时间线：
  PeiLink 主应用 → 底部导航"Echo"
  这里聚合了所有角色的 Echo 动态，按时间排序。

角色 Echo 空间：
  方式 A：羁绊页 → 点击任意角色 → 进入该角色的 Echo 空间
  方式 B：AI 世界桌面 → 角色页 → 点击"Echo"快捷入口
  方式 C：公共时间线 → 点击角色头像或名称

【Echo 空间包含】

- 动态列表：该角色发布的所有 Echo。
- 角色信息：头像、名称、关系、认识时间等。
- 空间装饰：角色空间的背景和主题装饰。
- 多个标签页：动态、相册、记忆 / 档案、关于等。

【互动功能】

- 点赞：点击 Echo 下方的心形图标即可点赞。
- 评论：点击评论图标进入评论区，可以发表评论，角色和其他角色可能会
  回复。
- 发布 Echo：在角色空间中点击发布按钮，可以以角色身份发布一条 Echo。
- 自动 Echo：角色会根据生活状态自动发布 Echo，不需要你手动操作。

【多角色公共时间线】

底部导航的 Echo 页面是公共时间线，会聚合所有角色的动态，按时间排序。
你可以在这里一站式浏览所有角色的最新生活动态。

【提示】Echo 数据是按角色独立存储的。删除某个角色的聊天记录不会影响
该角色的 Echo。

21. 多角色数据说明
================================================================================

PeiLink 支持创建和管理多个角色。理解多角色数据的隔离方式很重要。

【按角色独立的数据】

以下数据是每个角色独立存储的，不会互相混淆：

- Memory：每个角色有自己的记忆，A 角色的记忆不会出现在 B 角色中。
- Echo：每个角色有自己的生活动态和空间。
- 活动 / 消息状态：每个角色的在线状态独立计算。
- 聊天记录：每个角色的对话独立保存。
- 角色头像及资料：每个角色有自己的头像和设定。
- 重新开始：每个角色的重置操作独立，不影响其他角色。

【聚合展示的数据】

以下功能会聚合多个角色的数据进行展示：

- Echo 公共时间线：聚合所有角色的 Echo，按时间排序。
- PeiLink Life 最近动态：聚合多个角色的生活动态，按时间排序去重。
- 羁绊页：展示所有角色的关系等级和状态。
- 消息列表：列出所有角色和群聊的会话。

【理解要点】

"拥有多个角色时，并不是所有数据都混在一起。"

角色的核心数据（记忆、聊天、资料、Echo）都是严格按角色隔离的。只有
在展示层面（如公共时间线、Life 动态聚合）才会把多个角色的内容放在
一起浏览。

这样设计的好处是：即使你有很多角色，每个角色仍然保持独立的个性和
记忆，不会出现 A 角色知道了 B 角色的事情这种串档情况。

22. 删除聊天记录 / 重新开始角色 / 删除角色的区别
================================================================================

这是三个完全不同的操作，请务必仔细阅读，避免误删重要数据。

────────────────────────────────────────────────────────────────────────────────
操作一：删除聊天记录
────────────────────────────────────────────────────────────────────────────────

【入口】聊天页 → 右上角"..." → 删除聊天记录

【作用范围】
只删除当前角色的聊天记录（Chat History）。

【不会删除】
- Echo 及生活动态
- Life 数据
- Memory（长期记忆和待审核记忆都不会删除）
- 关系 / 羁绊等级
- 角色资料和设定
- 角色头像

【说明】
删除聊天记录后，聊天页会变成空白，但角色的记忆、Echo、关系等都完
整保留。角色在后续聊天中仍然可以参考之前的 Memory。

【可逆性】
删除后无法恢复，请谨慎操作。

────────────────────────────────────────────────────────────────────────────────
操作二：重新开始角色
────────────────────────────────────────────────────────────────────────────────

【入口】
- 聊天页 → 右上角"..." → 重新开始角色
- 角色管理页 → 对应角色 → 重新开始角色

【作用】
用于重新开始当前角色的聊天与本轮生活线。

【会清理】
- 当前角色的聊天记录
- Echo 运行数据
- Life 运行数据
- 主动发言状态
- 自动 Echo 等运行状态

清理完成后，会重新执行角色的初始化 Echo。

【会保留】
- 角色资料（名称、性别、简介、性格等）
- 角色设定 / 档案
- Memory（所有记忆都保留）
- 关系 / 羁绊等级
- 用户设置
- API 配置等长期数据

【说明】
重新开始角色相当于让角色"重新活一遍"，但角色的核心身份和记忆都保
留。适合在你觉得当前对话走向不理想，想重新开始但又不想丢失角色设定
和记忆时使用。

【可逆性】
重新开始后，被清理的聊天记录和运行数据无法恢复。

────────────────────────────────────────────────────────────────────────────────
操作三：删除角色
────────────────────────────────────────────────────────────────────────────────

【入口】
- 聊天页 → 右上角"..." → 删除角色
- 角色管理页 → 对应角色 → 删除角色

【作用】
永久删除整个角色及其所有关联数据。

【重要警告】
删除角色是不可逆操作！删除前强烈建议先导出 .pei 文件进行备份。

删除角色会移除该角色的所有数据，包括但不限于：
- 角色资料和设定
- 聊天记录
- Memory（所有记忆）
- Echo 及生活动态
- Life 运行数据
- 关系 / 羁绊等级
- 角色头像

【说明】
- 如果该角色有关联的纪念日，纪念日本身不会被删除，但关联关系会失效。
- 删除后角色会从消息列表、羁绊列表、角色管理列表中完全消失。
- 无法撤销删除，请务必确认后再操作。

【可逆性】
完全不可逆。除非你之前导出了 .pei 备份文件并重新导入，否则无法恢复。

────────────────────────────────────────────────────────────────────────────────
三者对比总结
────────────────────────────────────────────────────────────────────────────────

| 操作         | 聊天记录 | Memory | Echo | 角色资料 | 关系 | 可逆吗 |
|-------------|---------|--------|------|---------|------|--------|
| 删除聊天记录 | 删除    | 保留   | 保留 | 保留    | 保留 | 不可逆 |
| 重新开始角色 | 删除    | 保留   | 重置 | 保留    | 保留 | 不可逆 |
| 删除角色     | 删除    | 删除   | 删除 | 删除    | 删除 | 不可逆 |

23. 导出角色与备份建议
================================================================================

【为什么要备份】

PeiLink 的数据存储在你的设备本地。如果卸载应用、更换设备、或意外删除
角色，没有备份的话数据将无法恢复。因此定期备份非常重要。

【导出角色】

进入方式：
- 聊天页 → 右上角"..." → 导出角色
- 角色管理页 → 对应角色 → 导出角色

导出后会生成一个 .pei 格式的文件，包含该角色的完整资料。你可以将文件
保存到安全的位置（如云盘、电脑等）。

【.pei 文件包含】

- 角色基本资料（名称、性别、简介等）
- 角色设定（性格、外貌、背景故事、关系等）
- 角色档案
- Memory（长期记忆）
- 其他角色级数据

【备份建议】

1. 定期导出：建议每隔一段时间导出一次重要角色的 .pei 文件。
2. 重大操作前备份：在执行"重新开始角色"或"删除角色"之前，务必先
   导出备份。
3. 多位置保存：不要只把备份文件存在手机里，建议同时保存到电脑或云盘。
4. 更换设备时：先在旧设备上导出所有角色，在新设备上安装 PeiLink 后
   逐一导入。

【注意】
- 当前测试版暂不支持云同步功能，所有数据仅保存在本地。
- 导出的 .pei 文件可以通过第 8 章描述的方式重新导入。

   Life 页面的"世界状态"目前主要来自角色活动数据，不是真正的全局世界
   状态。

3. 日历功能基础
   当前日历只能查看日期和节日，不能添加事件、不能读取角色或纪念日数据。

4. 纪念日不影响 AI 聊天
   纪念日数据不进入聊天 Prompt，AI 不会自动在聊天中提及纪念日。

5. 无云同步
   所有数据存储在本地，卸载应用或更换设备需手动备份和恢复。

6. API 配置需要用户自行解决
   PeiLink 不提供 AI 模型，用户需要自行获取和配置 API Key，相关费用
   由服务商收取。

7. 部分 Life 应用不可点击
   相册、音乐、礼物、日记、世界等应用当前为占位状态，不可点击。

8. 群聊功能仍在完善
   虽然群聊已可创建和使用，但部分高级功能可能尚未完善。

26. 常见问题 FAQ
================================================================================

Q1：为什么 AI 不回复？
A：可能的原因包括：1) 没有配置 API 或 API Key 无效；2) 网络连接异常；
3) 模型服务商账户余额不足或额度用完；4) Base URL 或模型名称填写错误。
建议先到"设置 → 模型与 API"中检查配置并测试连接。

Q2：API 是什么？
A：API（应用程序编程接口）在这里指 AI 模型服务商提供的接口服务。
PeiLink 通过这个接口把你的消息发送给 AI 模型，并接收回复。你需要在
对应服务商处注册账户并获取 API Key 才能使用。

Q3：不配置 API 能聊天吗？
A：不能。角色无法回复消息。但你仍然可以使用 Echo、Life、日历、纪念日、
Guide 等不需要 AI 的功能，也可以创建角色和填写资料。

Q4：API Key 保存在哪里？
A：API Key 使用设备系统提供的安全存储能力保存在你的本机上。PeiLink
不会将你的 API Key 上传到任何第三方服务器。但在调用你选择的模型服务
时，认证信息需要用于对应服务的请求，这是正常的 API 调用流程。

Q5：为什么角色显示"忙碌中"？
A：角色的状态来自其活动 / 生活数据映射，不是随机显示的。"忙碌中"表示
角色当前的活动状态被映射为忙碌。这不影响你发送消息，角色仍会回复。

Q6：为什么角色忘记了一件事？
A：可能的原因：1) 这件事没有被整理成 Memory，只是在聊天记录中，而聊天
记录可能已被删除；2) Memory 还在待审核列表中，尚未采纳；3) 模型本身的
上下文限制，太久远的 Memory 可能没有被包含在当前对话的上下文中。建议
检查 Memory 页面，确认重要信息是否已被采纳为长期记忆。

Q7：Memory 和聊天记录有什么区别？
A：聊天记录是每一条对话的完整保存，按时间排列。Memory 是从聊天中提炼
出的重要信息，经过审核后单独保存，角色会在后续聊天中参考。删除聊天记
录不会删除 Memory。详见第 14 章。

Q8：为什么整理 Memory 后没有立刻出现？
A：从聊天整理出的记忆会先进入"待审核"列表，需要你手动确认采纳后才会
进入长期 Memory。这是为了确保记忆的准确性，请切换到"待审核"标签查看。

Q9：删除聊天会不会删除 Memory？
A：不会。删除聊天记录只清除对话历史，长期 Memory 和待审核 Memory 都完
整保留。角色在后续聊天中仍然可以参考之前的记忆。

Q10：重新开始角色会删除什么？
A：会删除聊天记录、Echo 运行数据、Life 运行数据、主动发言状态和自动
Echo 状态，然后重新初始化。但会保留角色资料、设定 / 档案、Memory、关
系 / 羁绊、用户设置和 API 配置。详见第 22 章。

Q11：删除角色能恢复吗？
A：不能。删除角色是永久操作，所有关联数据都会被移除。除非你之前导出了
.pei 备份文件并重新导入，否则无法恢复。删除前务必备份！

Q12：.pei 是什么？
A：.pei 是 PeiLink 的角色文件格式，包含角色的完整资料（设定、档案、
Memory 等）。用于角色的备份、迁移和分享。

Q13：怎么备份角色？
A：进入聊天设置或角色管理页，点击"导出角色"，会生成一个 .pei 文件。
将文件保存到安全位置即可。建议定期备份，重大操作前务必备份。

Q14：Echo 是什么？
A：Echo 是角色的生活动态，类似朋友圈。角色会发布自己的生活动态，你可
以浏览、点赞、评论。底部导航的 Echo 是所有角色的公共时间线，角色空间
是单个角色的 Echo 主页。

Q15：为什么 Life 里的部分 App 点不了？
A：相册、音乐、礼物、日记、世界等应用当前测试版暂未开放，属于占位入口。
这是正常的，不是 Bug，后续版本会逐步开放。

Q16：日历为什么现在只能看日期？
A：当前日历是基础本地月历，只提供日期浏览和节日标注功能。AI 记录、事件
添加、Echo 联动等功能属于后续计划，尚未实现。

Q17：纪念日会不会影响 AI 聊天？
A：不会。纪念日数据不进入聊天 Prompt，也不影响 AI 的聊天内容。它是一个
纯本地的生活记录工具。

Q18：多个角色的 Memory 会不会串？
A：不会。每个角色的 Memory 是完全独立存储的，A 角色的记忆不会出现在 B
角色中，也不会互相影响。

Q19：Guide 会不会消耗 API？
A：不会。Guide 是完全本地的说明中心，不调用 AI 模型，不消耗 API 额度，
也不需要联网。

Q20：怎么反馈 Bug？
A：方式一：侧边栏 → 设置 → 反馈与建议，会打开腾讯问卷。方式二：Guide
页面 → 帮助与反馈，可以填写表单后跳转问卷。反馈时建议提供问题描述、操
作步骤、是否可复现、截图、使用的模型和大概发生时间。注意不要在反馈中
提交完整的 API Key。

27. Bug 与建议反馈方式
================================================================================

PeiLink 内测期间，你的反馈对我们非常重要。

【反馈入口】

方式一：设置页反馈
  侧边栏 → 设置 → 反馈与建议
  会直接打开腾讯问卷页面。

方式二：Guide 页反馈
  打开 Guide → 帮助与反馈卡片
  会先进入一个反馈表单页面，填写后自动复制内容并跳转到腾讯问卷。

【反馈表单说明】

通过 Guide 进入的反馈页面可以填写：
- 反馈类型：Bug 反馈 / 功能建议 / 体验问题 / 其他
- 标题：简要描述问题（最多 60 字）
- 内容：详细描述（最多 1200 字）
- 联系方式（可选）：邮箱、微信等
- 截图（可选）：可以添加一张截图

填写完成后点击"前往问卷提交"，内容会自动复制，在问卷中粘贴即可。
如果添加了截图，需要在问卷的上传项中选择该截图。

【建议提供的信息】

为了帮助我们更快定位和解决问题，反馈 Bug 时建议提供：

1. 问题描述：遇到了什么问题，现象是什么。
2. 操作步骤：从哪里开始操作，一步步做了什么。
3. 是否可以稳定复现：每次都出现，还是偶尔出现。
4. 截图：问题发生时的界面截图。
5. 使用的模型 / Provider：例如 DeepSeek、火山方舟等。
6. 大概发生时间：便于排查日志。

【重要提醒】

不要在反馈截图或文字中提交完整的 API Key！如果截图中包含 API 配置页面，
请先涂抹或遮挡 Key 部分再提交。

【隐私说明】

提交反馈时，应用仅附加 PeiLink 版本、系统版本、基础设备信息和时间。
不会读取你的聊天记录、角色资料或其他私人数据。

29. 数据安全与 API Key 注意事项
================================================================================

【数据存储】

- PeiLink 的所有数据（角色资料、聊天记录、Memory、Echo、纪念日等）均
  存储在你的设备本地。
- 当前测试版不提供云同步功能，数据不会自动上传到云端。
- 卸载应用会清除所有本地数据，请务必先备份重要角色。

【API Key 安全】

- API Key 使用设备系统提供的安全存储能力（flutter_secure_storage）保存
  在本机，受到系统级别的保护。
- PeiLink 不会将你的 API Key 上传到任何第三方服务器。
- 但在调用你选择的 AI 模型服务时，API Key 作为认证信息需要发送给对应
  的模型服务商，这是正常的 API 调用流程，无法避免。
- 请勿将 API Key 分享给他人，也不要在反馈 Bug 时提交完整的 Key。

【API 费用】

- PeiLink 本身不收取任何 AI 调用费用。
- 你使用自己配置的 API 时，产生的所有费用由对应的模型服务商收取。
- 费用、额度限制、服务可用性均由服务商决定，PeiLink 无法控制。
- 建议定期检查你在各服务商处的账户用量和余额。

【角色数据安全】

- 每个角色的数据独立存储，删除一个角色不会影响其他角色。
- "删除聊天记录"和"重新开始角色"不会删除 Memory，但"删除角色"会删除
  所有数据。
- 建议定期导出 .pei 文件备份重要角色。
- 导出的 .pei 文件包含角色的完整数据，请妥善保管，不要随意分享给不信任
  的人。

【反馈隐私】

- 提交反馈时，应用仅收集版本号、系统版本、设备基础信息和时间。
- 不会自动读取或上传你的聊天记录、角色资料、Memory 等私人数据。
- 你主动填写的反馈内容和选择的截图会提交到腾讯问卷。
